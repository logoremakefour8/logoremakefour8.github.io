PPTX Tools

PPTX Viewer

Select a file for reference, or enter a public PPTX URL to show it in the PowerPoint web viewer.

The Office web viewer must be able to access the PPTX URL. A local file selected above cannot be passed directly to the online viewer; upload it to a host that provides a public URL first.

PPTX Converter

PPTX Creator

Create a new presentation, add slides and images, then save it as a PPTX file.

PPTX Editor

This editor creates and exports a new deck. It does not import and preserve the original contents of an existing PPTX file.
